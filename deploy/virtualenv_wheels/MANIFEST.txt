# virtualenv bootstrap wheel manifest — 兩個 profile 共用
# Built for: 任何 >= 3.6 的船端 python（這一組全部宣告 Requires-Python >=3.6，
#            Bionic 的 3.6.9 與 Jammy 的 3.10 都吃得下）
# Files    : 8 wheels
#
# 這一組是「在主環境（非 venv）離線補上 virtualenv」用的，由 install_virtualenv_offline.sh
# 以 pip install --user --no-index --find-links 安裝。它是船上**每一個** venv 的前提。
#
# 為什麼需要這份 manifest：OTA 走 SFTP，少送或截斷一個檔的話，失敗會晚到 pip 解析相依
# 那一刻才以「找不到相依」的形式浮出來 —— 而那時 deploy_offline.sh 已經動過機器了。
# deploy_offline.sh 的 preflight 會在**確定需要 bootstrap 時**校驗這份（已經有 virtualenv
# 的機器不該因為這個目錄少一個檔而卡住）。
#
# 為什麼版本偏舊：virtualenv 20.17.1 是最後一版支援 3.6 的；importlib-metadata 4.8.3 /
# importlib-resources 5.4.0 / zipp 3.6.0 / filelock 3.4.1 / platformdirs 2.4.0 /
# typing-extensions 4.1.1 / distlib 0.4.0 同理。在真的 Bionic（3.6.9）上實測可安裝，
# 並且裝出來的 virtualenv 能建出可用的 3.6.9 venv。
#
# 重建（有網路的機器上，見 deploy/README.md）：
#   pip download virtualenv --python-version 36 --only-binary=:all: -d deploy/virtualenv_wheels
#   cd deploy/virtualenv_wheels && sha256sum *.whl > MANIFEST.txt   # 檔頭註解請保留/補上
#
# 校驗基準目錄就是本目錄。不要併進 deploy/MANIFEST.txt。
#
